The rule read "Never add a `Signed-off-by:` line", which reads as if the
commit should not have one at all. That contradicts the DCO and the
"Commits" section below, which requires a sign-off matching the commit
author and forbids removing an existing one. The prohibition is on the
agent supplying the trailer, not on the trailer existing.

State both halves: every commit carries a sign-off from the human
responsible for the work, and an agent never writes, edits or copies one,
because only a human can certify the DCO
(doc/contribute/guidelines.rst).
