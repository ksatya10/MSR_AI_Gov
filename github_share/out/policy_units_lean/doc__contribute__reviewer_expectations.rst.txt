[Reviewer Expectations]

- When using AI tools to assist in reviewing code or drafting responses:

  - Reviewers are responsible for following up on comments generated by the AI
    tools they may be using (e.g. GitHub Copilot).
  - Reviewers must never paste raw, unverified LLM output as a PR comment.
  - In general: all AI-generated feedback must be vetted, verified, and
    contextualized by a human reviewer who assumes full accountability for the
    accuracy and tone of the comment or review.
